# Outcome

Attach a complete card like a stamp, transform its parent, then detach or reattach the child without losing identity.

## Design and constraints

Build fresh code in `packages/card-engine/` and new examples, not incremental changes to legacy engine files. Backward compatibility is out of scope. Read the full accepted requirements in parent specification #1; this slice adds only the behavior listed below. Keep app/lab labels and accessibility text English; localization may be added later. Use the same public interface in consumers and tests. Do not publish/deploy as part of implementation.

## Scope

- Introduce explicit attach/detach relations, single spatial parent and acyclic nested attachments with per-child anchors, pivots, offsets and local transforms.
- Compose child pose from the current parent surface before projection. Preserve child faces/elements and local animations while inheriting parent motion/scale/rotation/flip.
- Allocate zone slots only to roots while every member retains zone membership/capacity participation. Project-approved parent moves include descendants atomically.
- Define card-target drop intents versus zone placement. Child-only drag requires explicit reposition/detach/reject policy; parent removal requires explicit descendant disposition.
- Handle parent-plus-child selection without double displacement; preserve continuous poses on attach/detach/reattach during motion.

## Acceptance criteria

- [ ] Nested children follow parent resize and transforms without double projection/scaling or DOM replacement.
- [ ] Self/cyclic/multiple-parent relations reject atomically. Denied descendant or insufficient capacity rejects the full move.
- [ ] Hidden anchor/face and late relation cleanup behave correctly; detach starts at the current displayed pose.
- [ ] Independent inspection and selection remain available; removal never silently destroys attached cards.

## Runnable lab scenario

Attach two cards to a parent, attach a grandchild, drag the parent across zones while flipping, then detach a child in flight.
