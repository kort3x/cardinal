## Delivered behavior

The header's **Tutorial** button starts a 14-step, opt-in overlay tour. Steps
explain engine versus consumer responsibilities, selection, zones, the draw
stack, arrangements, drag tuning, motion, dimensions, faces, inspection,
elements, and diagnostics. Close/Finish/Escape ends the tour; reopening starts
at the first step.

The overlay reveals relevant toolboxes, scrolls them into view, clips the
spotlight to visible bounds, and keeps navigation available while long text
scrolls. The background is inert while the tour runs. Closing restores prior
toolbox and inert states and focus. Tutorial navigation makes no scene
transactions and preserves card data and selection. Existing running animation
continues; the tutorial blocks new background input rather than stopping motion.

## Corrections established during verification

- Initial narrow-screen touch navigation failed on the long Elements step:
  Next extended below the panel. The panel now reserves header/footer space
  and scrolls only the explanatory text. The regression checks that Next is
  inside the panel and receives input on every narrow-screen step.
- Keyboard Enter initially failed because the CDP helper omitted the carriage
  return needed for native button activation. The corrected helper sends the
  key code and text; the assertion remains an actual keyboard interaction.
- Two existing layout assertions expected the pre-inspection panel count and
  order. They now include the existing Inspection toolbox. No toolbox was
  removed to satisfy the old assertions.
- Review identified Escape after touch focus loss and ambiguous restoration of
  rebuilt zone details. Document capture handles Escape, and restoration uses
  the owning zone ID. The retained default Ocean count is 48: `ice-demo` plus
  the 47 generated cards, not just the generated array's length.
